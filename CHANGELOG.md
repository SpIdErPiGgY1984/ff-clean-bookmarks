# Changelog

## 1.0.0 · 23 October 2026

First Spiderpiggy release based on Virtuos86's My Clean Bookmarks 0.5.41.

- New compact Light and Spiderpiggy Dark interfaces, theme selector and original user CSS compatibility.
- Halloween, Christmas and New Year skins with an optional local-date calendar.
- Redesigned options, Dutch interface translation, improved nested-folder alignment and custom Spiderpiggy icons.
- 850 ms default hover-to-open delay.
- Bookmark titles and URLs are displayed using safe DOM text and attributes rather than direct HTML concatenation.
- Optional HTTPS-only favicon loading, local letter placeholders and advanced page-declared favicon discovery requiring separate Firefox permissions.
- Removed default access to all websites, the unused background script, obsolete image assets and intermediate test documents.
- Retained credits and third-party license notices.

**Known limitation:** Telenet TV may not provide a usable favicon and can display a letter instead.

**Release note:** Source package is ready for GitHub. Firefox Add-ons publication requires Mozilla review, signing and license-provenance verification; no approval is implied by this version number.
